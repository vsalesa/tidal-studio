Tidal Studio

This installer contains everything Tidal Studio needs. Nothing is downloaded:

  • Tidal Studio (the web studio and the Maestro assistant)
  • TidalCycles with its own Haskell (GHC)
  • SuperCollider, SuperDirt and the Dirt-Samples sounds
  • Python

It installs Tidal Studio in Applications and its engine in /Users/Shared/TidalStudio (about 3 GB). It does not touch any SuperCollider, Haskell or Python you already have.

Español: este instalador lo lleva todo dentro y no descarga nada. Instala Tidal Studio en Aplicaciones y su motor en /Users/Shared/TidalStudio (unos 3 GB). No toca el SuperCollider, Haskell o Python que ya tengas.
